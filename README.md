## 💻 Projects

### 🧪 AgentCheck — AI Agent Evaluation & Reliability Platform

A platform that evaluates AI agent reliability by checking tool selection, argument correctness, and output accuracy.

- ✅ Evaluates AI agent tool selection
- 🔍 Validates tool arguments and outputs
- 📊 Supports batch evaluations and failure analysis
- 🧪 Includes automated tests using Pytest

**Tech Stack:** Python · FastAPI · Streamlit · Pandas · Pytest
