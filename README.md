### 🧪 AgentCheck — AI Agent Evaluation & Reliability Platform

A lightweight platform that evaluates AI agent behavior by checking tool selection, argument correctness, and output accuracy — with batch testing and failure reports.

**Tech Stack:** Python · FastAPI · Streamlit · Pandas · Pytest

**Key Features**
- ✅ Evaluate AI agent tool selection
- 🔍 Validate tool arguments and outputs
- 📊 Run batch evaluations and analyze failures
- 🧪 Automated tests using Pytest
- 📥 Export evaluation results
